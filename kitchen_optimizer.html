🎓 3. Viva Defense Questions & Answers

Q1: Why does Breadth-First Search (BFS) fail to find the optimal path?

BFS measures path length by edge depth count, not edge step costs $g(n)$. Because the sequential path takes 5 steps ($S_0 \rightarrow A \rightarrow B \rightarrow C \rightarrow D \rightarrow G$) while the parallel path takes 5 steps ($S_0 \rightarrow X \rightarrow Y \rightarrow Z \rightarrow W \rightarrow G$), BFS returns whichever path it encounters first in level order without considering time cost.

Q2: How does Depth-First Search (DFS) handle Dead-End nodes (E1-E5)?

DFS blindly follows the deepest branch first. When it expands an invalid state (such as E1 - cooking raw chicken), it discovers no valid successor edges exist and is forced to backtrack. This wastes node expansions compared to A* Search.

Q3: Why is $h(n) = \max(\text{Stove Time}, \text{Rice Cooker Time}) + 2B$ admissible?

Because the Gas Stove and Rice Cooker can operate simultaneously in parallel, total passive cooking time is bounded by whichever appliance requires the most remaining time ($\max$). Since equipment cannot finish faster than its physical cycle, this estimate never overestimates $h^*(n)$.
